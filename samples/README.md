# Sample panoramas

Three equirectangular panoramas (4096×2048) for trying the studio without hunting
for your own 360° photos. Drag them onto the editor, or use **Add 360° images**.

| File | Source |
| --- | --- |
| `lythwood_lounge.jpg` | [Poly Haven](https://polyhaven.com/a/lythwood_lounge) — Greg Zaal |
| `lythwood_room.jpg` | [Poly Haven](https://polyhaven.com/a/lythwood_room) — Greg Zaal |
| `reading_room.jpg` | [Poly Haven](https://polyhaven.com/a/reading_room) — Greg Zaal |

All three are released by Poly Haven under [CC0](https://creativecommons.org/publicdomain/zero/1.0/)
(public domain): usable for anything, including commercial work, with no attribution
required. They were downscaled from 8192×4096 to keep this repository small; the
originals are on Poly Haven.
